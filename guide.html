1. Purpose

This guideline is the written version of the Knowledge Transfer on 14 September 2026. From 18 September 2026, all AWS Partner Network (APN) opportunities are submitted in Lark Base — not on the new APN website. Do not create a live customer opportunity in this Base until 18 September.

Open the Base: https://g-asiapac.sg.larksuite.com/base/Xtx2b48FRabZewsZtqol0lfagOb

Longer click-path in the APN folder: APN opportunity process

2. Why Lark

AWS launched a new APN. That new APN has limits for our team. You type the opportunity in Lark. Lark still sends it to APN. You are using a different door into the same APN.

5. Create (first-time opportunity)

Two ways. Form sends in one step. Grid + Add Record saves a draft until you tick Submit.

5.1 Send now — Form

  1. Open APN Oppt Submission Table.
  2. Use the Form view (Fill, not Edit).
  3. Fill required fields. Follow the format rules in section 9.
  4. Click Submit.
  5. Open Grid. Watch Sync_Status for about one minute.

5.2 Draft — Grid + Add Record

  1. Open Submission → Grid.
  2. Click + Add Record on the Grid toolbar. Do not click + New under the table list.
  3. Fill the new row. Leave Action as Create.
  4. Leave Submit and Submit_to_AWS unticked. Leave Sync_Status empty. That is a draft — AWS has not received it.
  5. When ready, tick Submit and Submit_to_AWS. If Sync_Status does not move, set Pending. Keep Action as Create. Wait about one minute.

Until 18 September 2026, you may practise Add Record but do not tick Submit on a real customer.

If Success. AWS has the create. That is not Approved. Check AWS_Review_Status after about six hours.

If Failed. Side Peek from Opportunity ID. Read Sync_Message. Fix that field. Click Retry. Leave Action as Create. Do not click Update on a Failed create.

Lark Messenger also sends Success or Failed with Sync_Message. The blue button opens the row.

6. Update (stage or requirements changed)

  1. Do not type in the Status table.
  2. Side Peek. Check AWS_Review_Status.
  3. If it is not Approved, stop. Do not Update if Create is still Failed.
  4. If Approved: edit fields. Click Update. Leave Action as Update.
  5. Wait about one minute.

If Failed. Fix Sync_Message. Click Update again. Do not click Retry on an Update.

7. Referral (sales admin)

Compulsory for sales admin. Extra knowledge for account managers. No Form.

  1. Open APN AWS Invitations.
  2. Find the row (country + engagement title).
  3. Set Decision to Accept (or Reject).
  4. Set Assignee to the account manager.
  5. Set Sync_Status to Pending. Then wait.
  6. AWS_Opportunity_ID appears when it lands. Status still takes about six hours.
